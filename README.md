## 🤖 1. Google Antigravity CLI Installer

Fast, one-line automated installer for Google Antigravity AI CLI on Termux.

### 🚀 Quick Run:
```bash
curl -fsSL https://raw.githubusercontent.com/OddBoyXD/scripts/main/antigravity.sh | bash
```

### ✨ Features:
* 🔍 **Pre-Flight Check**: Checks architecture, RAM, and storage before installing.
* ⚡ **Fast Cloudflare Mirrors**: Speeds up package downloads.
* 🐧 **glibc Auto-Configuration**: Automatically sets up GNU C runtime.
* 🧹 **Auto-Cleanup**: Deletes temporary archives to save storage space.
